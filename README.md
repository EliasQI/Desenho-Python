# Desenho com Python

Projeto desenvolvido para explorar a criação de desenhos por meio de programação utilizando Python.

## Sobre o projeto

O **Desenho-Python** tem como objetivo utilizar código para criar representações gráficas, explorando a relação entre programação, lógica e criatividade.

O projeto demonstra como conceitos de programação podem ser aplicados à construção de elementos visuais, tornando o aprendizado mais prático e interativo.

## Objetivos

- Praticar conceitos da linguagem Python.
- Explorar a criação de desenhos por meio de código.
- Desenvolver o raciocínio lógico e a resolução de problemas.
- Aplicar estruturas de programação em atividades visuais.

## Tecnologias utilizadas

- **Python**

As bibliotecas e ferramentas gráficas utilizadas podem ser detalhadas nesta seção após a verificação do código-fonte.

## Como executar

### Pré-requisitos

- Python instalado no computador.

### Execução

1. Clone este repositório:

   ```bash
   git clone https://github.com/EliasQI/Desenho-Python.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Desenho-Python
   ```

3. Execute o arquivo Python principal:

   ```bash
   python nome_do_arquivo.py
   ```

   Substitua `nome_do_arquivo.py` pelo nome do arquivo principal do projeto.

## Aprendizados

Este projeto representa uma oportunidade de praticar Python e explorar aplicações visuais da programação, reforçando conceitos de lógica e organização do código.
